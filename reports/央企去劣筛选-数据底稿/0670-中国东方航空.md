## ③ 利息覆盖倍数（FY2025，EBIT = 利润总额 + 利息费用）

- 利润总额：**2.74亿元**
- 利息费用（费用化，财务费用项下）：**41.85亿元**
- EBIT = 2.74 + 41.85 = **44.59亿元**
- **利息覆盖倍数 = 44.59 / 41.85 = 1.07倍**
- 交叉验证：新浪财经「利息支付倍数」2025 = 106.914% → 1.07倍，**双源一致**；东方财富 INTSTCOVRATE = 1.0655，同样一致。
- 说明：EBIT 为正，可勉强覆盖利息，但缓冲极薄。租赁负债利息已包含在费用化利息中（东航租赁负债体量大，利息负担重）。若包含资本化利息，覆盖倍数更低。**口径：费用化利息，未含资本化利息 → 标"数据不足"项。**

## ⑦ 5年总股本膨胀（2020年末 → 当前）

- 2020年末总股本：**16,379,509,203股（163.80亿股）**
- 当前总股本：**22,087,736,670股（220.88亿股）**（2025-11-11 回购注销后，至2026-09-16未变）
- **膨胀幅度 = +34.85%**
- 原因（东方财富股本结构变动记录）：
  1. 2021-11-09 **增发A股上市** → 163.80亿股 → 188.74亿股（2021年定增）
  2. 2023-01-12 **增发A股上市** → 188.74亿股 → 222.91亿股（2022年末完成的定增）
  3. 2024-11-11 网下配售股份上市（股本不变，222.91亿股）
  4. 2025-11-11 **回购注销** → 222.91亿股 → 220.88亿股（注销约2.04亿股A股）
- 来源：东方财富 CapitalStockStructure/PageAjax（SH600115）。2019-08-30至2021-11-09 无变动记录，故2020年末值取自2019-08-30记录 → **单一来源（推算）**。
- 结论：**2020–2023年多轮定增导致股本膨胀 +36.1%（至222.91亿股，峰值），2025年回购微降**。每股权益被持续摊薄，与同期巨额亏损叠加，是ROE长期为负的核心原因之一。

## 数据缺口 / 风险提示

1. **利息覆盖口径**：仅含费用化利息，资本化利息金额未获取 → 「数据不足」，真实覆盖倍数更低。
2. **FCF口径**：新租赁准则导致 OCF 高估、Capex 低估（不含融资租赁飞机），5年累计FCF +244亿不代表可自由分配现金；建议按"OCF − Capex − 租赁本金偿付"重算（缺少租赁本金单列数）→ 「数据不足」。
3. **2020年末总股本**：东财股本结构在2019-08-30至2021-11-09间无记录，2020年末值系推算 → 「单一来源（推算）」，误差应在0.1%以内。
4. FY2025 归母净利与摊薄EPS×股本存在小额差异（-16.33亿 vs ≈-19.5亿），系加权平均股本/摊薄口径差异，不影响结论方向。
5. 未取2026年中报的资产负债率等最新数（本表要求最新财年=FY2025）。
