- 股本结构：内资股 1,778,845,451 股（57.00%）+ H股 1,341,737,757 股（42.99%）
- 历史股本变动（**推算+单源交叉**）：

  | 2016年 | **配售 189,000,000 股新H股** | +189,000,000 | 2,971,583,208 |

  | 2021–2026 | 无变动 | 0 | 3,120,583,208 |
- **重要更正**：任务背景中"国药控股2016年配售"成立（189,000,000股），但**该配售发生在2020年末之前**，因此对"2020年末→当前"的股本膨胀贡献为 **0**。2020年另有一次149,000,000股H股配售，完成时点落在2020年内（**推算**：由2020年加权平均股本 3,111百万股 略低于年末 3,120.6百万股 反推）。
- 推算依据（EPS反解，自洽性检验）：
  - 2015年：归母37.72亿 / EPS 1.36 = 2,774百万股 ≈ 配售前2,782.6百万股 ✓
  - 2017年：归母55.76亿 / EPS 1.88 = 2,966百万股 ≈ 配售①后2,971.6百万股 ✓
  - 2020年：归母71.87亿 / EPS 2.31 = 3,111百万股 ≈ 配售②后3,120.6百万股 ✓
  - 2025年：归母71.55亿 / EPS 2.29 = 3,124百万股 ≈ 3,120.6百万股 ✓
