- **5 年累计 FCF = −121.2 亿元（深度为负）**，符合新能源运营商"高 Capex、自由现金流被资本开支吞噬"的特征
- 5 年 OCF 累计 1,010.13 亿元，5 年 Capex 累计 1,131.33 亿元，**Capex/OCF = 112%**
- 唯一正 FCF 年份为 2022 年（+71.99 亿），系当年 OCF 异常高（296.05 亿，含可再生能源补贴回收集中到账），2023 年即回落

### ③ 利息覆盖倍数（FY2025，最新财年）
- 利润总额 = 71.19 亿元；利息费用（费用化）= 32.67 亿元
- **EBIT = 利润总额 + 利息费用 = 71.19 + 32.67 = 103.86 亿元**
- **利息覆盖倍数 = 103.86 / 32.67 = 3.18 倍**
- 口径：**仅费用化利息（财务费用中的利息费用）**。电力企业大量利息资本化（在建风电场），真实利息负担显著高于费用化口径，故 3.18 倍为**偏乐观的上限**
- IFRS 交叉验证（S9 比例法）：2025 年利息费用/营业额 = 500.63/4304.11 = 11.63% → 折 35.18 亿元；除税前盈利/营业额 = 24.01% → 折 72.64 亿元 → 覆盖 ≈ 3.06 倍。**两口径落在 3.05–3.20 倍区间，结论稳健（≈3.1 倍）**
- 历史趋势：利息费用 2016–2025 年基本在 28–36 亿元区间高位横盘，而利润总额 2025 年下滑 → 覆盖倍数随盈利下行而恶化

## 九、数据缺口与不确定性

1. **2016–2018 加权 ROE**：A 股 F10 无值。本底稿用"推算平均 ROE"（9.00 / 8.83 / 8.77）替代，与港股源（8.70 / 9.12 / 8.53）差 ±0.3pp。两种处理下的 10 年均值分别为 8.72% 与 8.71%，**对结论无实质影响**。（可信度：中）
2. **Capex 单一来源**：仅 S3 一个来源，无第二独立源。港股源"投资活动现金流净额"口径不同，未作为双源。故 ② 项 FCF 为**单一来源 + 推算**（可信度：中高）。
3. **利息费用仅费用化口径**：无法取得资本化利息金额，实际利息负担（含资本化）显著更高，③ 项 3.18 倍为上限值。（可信度：中）
4. **港股 IFRS 与 A 股 CAS 的收入/毛利率口径差异巨大**（详见第六节），任何跨市场比较必须先统一口径。
5. **定增规模未知**：向特定对象发行 A 股股票已获批但未发行，发行规模/价格未纳入本底稿，将直接影响未来股本膨胀率与资产负债率。
6. **A 股行情为单一来源**（腾讯）；H 股行情为双源。
7. **2025 年归母净利同比 −28.78%**，主因外生（来风偏弱 / 电价 / 补贴）抑或内生，需查年报分部数据，本底稿未覆盖。

## 十、可信度总评：**中高**

- 强项：核心财务数据（收入、利润、OCF、权益、股本、市值、股东）均来自交易所/接口一手数据，且多数完成双源验证；口径分歧已定位并解释。
- 弱项：2016–2018 ROE 与 Capex 为推算/单一来源；资本化利息缺失；A+H 合并市值为推算。
