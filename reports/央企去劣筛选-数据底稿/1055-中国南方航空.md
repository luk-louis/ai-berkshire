## ③ 利息覆盖倍数（FY2025，EBIT = 利润总额 + 利息费用）

- EBIT = 48.11 + 55.53 = **103.64亿元**
- **利息覆盖倍数 = 103.64 / 55.53 = 1.87倍**
- 交叉验证：新浪财经「利息支付倍数」2025 = 195.5701% → **1.96倍**（口径差异：新浪隐含利息约50.30亿元）。**两源接近但不等 → 标"双源（口径差异约5%）"**。
- 说明：EBIT 为正且缓冲优于东航，但租赁负债利息沉重；口径仅含费用化利息，未含资本化利息 → 部分「数据不足」。

## ⑦ 5年总股本膨胀（2020年末 → 当前）

- 2020年末总股本：**15,329,302,395股（153.29亿股）**
- 当前总股本：**18,120,970,492股（181.21亿股）**（2026-08-31，此后仅"债转股上市"微增）
- **膨胀幅度 = +18.21%**
- 原因（东方财富股本结构变动记录）：
  1. 2020-04-15 **增发H股上市** → 122.67亿股 → 128.76亿股（疫情前/初期H股定增）
  2. 2020-06-17 **增发A股上市** → 128.76亿股 → 153.29亿股（2020年A股定增）
  3. 2022-08-10 **增发H股上市** → 169.48亿股 → 173.17亿股
  4. 2022-11-23 **增发A股上市** → 173.17亿股 → **181.21亿股**（2022年定增，股本峰值）
  5. 2023–2026 股本基本持平，仅有「南航转债」转股带来的"债转股上市"微增（181.2089亿 → 181.2097亿股）
- 来源：东方财富 RPT_F10_EH_EQUITY（SECUCODE=600029.SH）。
- **口径说明**：2020年末值取自 2020-06-17 变动记录（下一笔记录为 2021-04-30，差 +52,355股），即2020年下半年无股本变动 → **推算/单一来源**，误差 <0.01%。
- 结论：与用户假设一致，**2020、2022年多轮定增（A股+H股）推动股本膨胀 +18.21%**；2023年后停止定增，转以可转债转股方式缓慢摊薄。

## 数据缺口 / 风险提示

1. **利息覆盖口径**：仅含费用化利息，资本化利息未获取；新浪与东财隐含利息口径差约5%（1.87 vs 1.96倍）→ 「口径差异」。
2. **FCF口径**：新租赁准则使 OCF 高估、Capex 低估（不含融资租赁/经营租赁飞机），5年累计FCF +525亿不代表可分配现金。需加回租赁本金偿付重算 → 「数据不足」。
3. **⑤ OCF/净利**：FY2024 分母仅1.54亿元，比率204倍无意义；FY2025 的14.23倍亦属"极薄利润"失真，**5年均值不适用**。
4. **2020年末总股本**：推算/单一来源（见⑦口径说明）。
5. 净利润总额系「营收×净利率」推算，非直接取自利润表 NETPROFIT 字段（该字段请求被接口拒绝）→ 标「推算」。
