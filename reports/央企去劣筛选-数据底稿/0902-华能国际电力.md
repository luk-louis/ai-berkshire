## ③ 利息覆盖倍数（FY2025）

- 利润总额 = 236.44亿元；利息费用（费用化）= 70.75亿元
- EBIT = 236.44 + 70.75 = **307.19亿元**
- **利息覆盖倍数 = 307.19 / 70.75 = 4.34倍**
- 口径：**仅费用化利息**（`FE_INTEREST_EXPENSE`=7,075,103,710），**不含资本化利息**。火电/新能源在建工程庞大，资本化利息规模可观，真实利息负担高于此。财务费用（含汇兑）= 67.54亿元，低于利息费用，说明有汇兑收益抵减。
- 来源：东财 F10 `RPT_F10_FINANCE_GINCOME` → 单一来源（结构化原始科目）
- 交叉参考：新浪「利息支付倍数」2025 = 450.07（口径不同，**不采用**）
- **历史对比**：2021年利息费用88.0亿而利润总额-140.2亿 → **EBIT(=-52.0亿) < 利息费用，利息保障倍数为负，即经营所得无法覆盖利息**（亏损年特征）

## 数据缺口

1. **资本化利息金额未知** → 利息覆盖倍数4.34倍偏乐观。华能在建工程规模巨大（总资产6117.9亿，固定资产比重62.7%），资本化利息可观。**这是本项指标的主要不确定性**
2. **每股收益数据源内部冲突**：新浪 `摊薄每股收益`=1.2425元（×156.98亿股 → 195.05亿，与净利润总额一致，疑为全口径），而 `加权每股收益`=0.74元（×156.98亿股 → 116.2亿，与归母净利144.10亿不符）。**建议以年报原文EPS为准**；本底稿归母净利一律以官方公告144.10亿元为准
3. **2021–2022年归母净利润为负**（-100.06亿 / -73.87亿），导致①⑤⑥十年/五年均值严重失真；建议并参考2023–2025三年均值（ROE均值14.48%、净利率均值5.94%、OCF/归母净利均值5.012）
4. **少数股东权益占比高**：净利润总额195.05亿 vs 归母净利144.10亿，差异50.95亿（26.1%），分析须严格区分口径
5. FY2025营收同比-6.62%与归母净利同比+42.17%背离，主因煤价下行带来成本改善，但**电量/电价/煤价拆分未采集**
6. 2016–2024逐年数据未做二手全量交叉（受检索次数限制，优先结构化F10接口）
